# temporal 标准入口

模块目标以 [goal.md](../goal.md) 为准；时间值、证据、PIT 选版及错误合同以 [spec.md](../spec.md) 为准。本页只提供入口，不增加第二套行为合同。

`UnixTimeNs` 表示 POSIX epoch 纳秒；六角色模型区分 `Known`、`Unknown` 和 `NotApplicable`。PIT 查询必须固定知识口径、权威作用域、快照、覆盖声明和策略。`SystemAsKnown` 还必须证明接收、消费边界及历史 cut。

独立 crate 通过门禁只说明本库候选可审查；真实来源、消费者接入和 `kernel` 时间公开面迁移分别验收。
