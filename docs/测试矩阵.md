# 验收矩阵入口

场景正文、Owner 与判据见 [spec.md](../spec.md) §22 和 §33；本页只登记本仓可执行的层次。一个测试函数覆盖某编号的部分断言，不等于该场景已整场验收。

| 层 | 本仓入口 | 结论范围 |
| --- | --- | --- |
| 公开面与编译负向 | `tests/api_compile.rs`、`src/lib.rs` doctest | 根导出、trait、私有字段和无单位隐式转换 |
| 数值、时钟、日期与六角色 | `tests/primitive_contract.rs`、`clock_contract.rs`、`precision_contract.rs`、`observation_contract.rs`、`profile_contract.rs`、`properties.rs` | 纯值和结构合同 |
| 身份、证据与上下文 | `tests/revision_contract.rs`、`evidence_contract.rs`、`context_contract.rs` | 结构与绑定；外部真实性仍由受信适配器负责 |
| PIT 与有效状态 | `tests/pit_contract.rs`、`effective_contract.rs` | 合成快照和证据上的纯规则，不代表真实消费方系统历史 |
| 消费方与迁移 | 各产品、Adapter、Runtime 与 `kernel` 仓 | 本仓不能代签；在各仓候选中单独留证 |

实际执行的命令、退出码、工具链、候选 SHA 与未覆盖项须另记验收证据。规格中 180 个场景不能按测试函数数量推定完成。
