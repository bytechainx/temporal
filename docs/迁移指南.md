# 从 kernel 迁移时间公开面的条件

本仓 `0.1.0` 是独立候选。`kernel` 的时间公开面仍由 `kernel` 仓负责；仅构建本仓不能证明消费者已完成唯一类型身份迁移。

1. 固定 `kernel` 当前 `main`、本仓候选、消费者、schema、策略与锁文件 SHA；核对旧基线差异。
2. 在消费者中用固定 Git commit 依赖本仓，显式转换时间值与错误，逐仓验证编译、单位、负 epoch、精度及业务时序。
3. 为各数据源和消费边界提供受信 release、receipt、availability、snapshot、cut、coverage 证据；将存储/协议/回测选择器与本仓纯规则做差分。
4. 消费者组合候选通过后，单独评审 `kernel` 移除时间公开项的破坏性版本与回滚方案；`time_storage` 的 PostgreSQL 投影留在存储适配器。

不得让最终依赖图同时暴露两份来源不同的绝对时刻类型；不能用本仓 `cargo test` 代替消费者、真实来源或 `kernel` 门禁。详细归属见 [spec.md](../spec.md) §24。
