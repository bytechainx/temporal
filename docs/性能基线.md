# 性能基线状态

受控机器、资源预算和对照候选尚未由模块 Owner 冻结，性能回归门禁状态为 **NOT_RUN**。本仓不得用共享 CI 的一次耗时建立跨机器阈值，也不得宣称固定纳秒延迟或 QPS。

冻结基线时记录 CPU、内存、操作系统、target、Rust 版本、优化级别、候选 commit、输入 seed、1/10/100 修订及 10³/10⁵ 候选的样本和分配/峰值工作内存。相同环境的中位数与已冻结基线比较；超过 [spec.md](../spec.md) §21.3 的回归幅度时阻断并评审。

覆盖矩阵由 `benches/spec_matrix.rs` 输出，每行一个 JSON 对象：`cell` / `n` / `median_ns` / `p95_ns` / `allocs_per_op` / `peak_rss_kib`。矩阵覆盖单位构造、checked add/sub、SystemTime 往返、三种舍入策略、六角色校验、单条可见性、1/10/100 修订、10³/10⁵ 候选，以及乱序、重复、撤回与覆盖不足四种变体。该文件只生成读数，不定义阈值；基线状态在参数冻结前保持 `NOT_RUN`。
