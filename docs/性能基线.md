## 回归判定

同一受控机器、同一 target 与工具链下，任一 cell 的 `median_ns` 或 `peak_rss_kib` 较本表回退超过 10% 时阻断并审议（[spec.md](../spec.md) §21.3）。`p95_ns` 与 `allocs_per_op` 只作记录，不单独触发阈值。机器、工具链、target、候选 commit 或采样策略变化时，本基线失效，须重新冻结。
